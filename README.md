# Tab Harbor · 标签港湾 v3.26.0

> 原名 Better Group Tabs,全面重构后启用新名称与新面貌。
> 内部存储键保持兼容:老用户安装后数据无缝延续。

**Tab Harbor 是一个 Local-first 的浏览器工作记忆系统:保存的不只是标签,而是你工作过程中的每一个现场。**

> Your tabs are temporary. Your work history shouldn't be. — 标签会关闭,工作脉络不该消失。

(Manifest V3,零依赖,数据仅存本地)
在 v1.1.0「保存/恢复」的基础上脱胎换骨:单写者数据层、崩溃快照、原生标签组互通、
按域名整理、命令面板、批量操作、重复保存统计,零依赖,数据仅存本地。

## 功能总览

**保存**
- 一键保存当前窗口 / 全部窗口(`Alt+S` / `Alt+Shift+S`),徽章显示分组数
- 可选:排除固定标签、排除当前页、忽略重复网址、忽略 chrome:// 等特殊页面
- 页面右键菜单「把此页面存为新分组 / 存入已有分组」
- **存为完整快照(MHTML)**:右键整页保存(可选权限 pageCapture,首次使用时申请);本体写入
  知识库文件夹 snapshots/,store 只留 SHA-256 清单
- **内容指纹**:右键生成(可选 scripting,页内计算 SHA-256);同页未变不重复入账;标题未变而
  内容变了 ⇒ 判为版本化并明示「内容确已变更」;洞察面板的判断显式、带理由、可撤销
- **存为摘录**:选中任意文字 → 右键「把选中文字存为摘录」(零新权限);摘录挂到该页面的观测上,
  同一网址的 ×N 徽章菜单可一键**复制全文**,「重复与相似」洞察中出现摘录片段;
  **开工后窗口与项目绑定**(会话级):绑定窗口里存的摘录自动归属该项目,菜单显示「日期 · 摘录 · 项目名」
- 保存后自动关闭已保存标签并打开管理页(均可关闭)

**管理页**(`chrome-extension://…/manager/manager.html`)
- **「今天」首页(默认)**:继续昨天的工作 —— 最近收工的项目一键开工、今日收工记录
  (点击进入当时现场)、今日摘录(带项目归属);**统一搜索**:在首页搜一次,跨 分组/项目/历史
  给全结果(点击跳转/定位/回现场);分组/工作区/时间轴三视图随时切换
- 分组卡片布局,按分组 ID 生成专属色相;置顶📌 / 归档 / 批量选择
- **拖拽整理**:组内排序、跨组移动、拖分组手柄排序、拖标签到「新建分组」直接建组;
  悬停折叠组自动展开、接近视口边缘自动滚动
- **搜索**:分组名 / 标题 / 网址实时过滤(轻量渲染,不重建 DOM);`/` 或 `Ctrl+F` 聚焦
- **命令面板 `Ctrl+K`**:搜分组直达恢复,或执行命令(新建 / 保存 / 整理 / 导出 / 设置)
- **恢复方式**:当前窗口后台 / 前台 / 新窗口 / **恢复为 Chrome 原生标签组**;
  支持**选择性恢复**(勾选部分标签)
- **按域名整理**:一键把所有标签按域名重新归组,支持规则(`github.com => 代码`,每行一条),操作可撤销
- **自动套用规则**:开启后,每次保存的标签自动按规则分流进对应分组(同名追加去重,无则建组)
- **相似分组洞察与共现图**:两分组网址重叠 ≥80% 时建议合并,一键合并(去重、可撤销);
  **共现**:工作现场里一起出现的来源对(按 (网址, 版本) 分节点 —— 同一网址换版后连向不同邻居),
  可导出为 Markdown —— 这层关联只有浏览器观测层能生成,笔记软件算不出来
- **高频域名 → 一键转规则**:洞察页按网址数汇总最常停留的域名,一键预填整理规则
  (跳到设置补全分组名),配合"自动套用规则"形成 行为 → 历史 → 洞察 → 规则 → 自动化 闭环
- **港湾周报**:时间轴顶部纯本地节奏摘要——"本周入港 N 次 · 比上周 ±X% · 最常停泊:host(N 次)",
  日期芯片一键**把这一天找回来**(当天记录并集转分组,可撤销)
- **变化摘要**(周报条下方):什么变了 —— 标题变版的来源(版本谱系)、项目来源集 ±、三周未回、新枢纽 host(结构化 delta,非生成式)
- **多步撤销**:`Ctrl+Z` / `Ctrl+Shift+Z` 撤销/重做最近 10 步列表级操作(删除/清空/合并/整理),
  合并式语义——只找回被删的,不覆盖期间的编辑;创建型操作(找回/快照转分组)为精确回滚
- **原生分组导入**:把当前窗口已有的 Chrome 原生标签组导入为持久分组
- **批量操作**:勾选多个分组 → 合并(去重)/ 导出 / 删除,全部可撤销
- **删除可撤销**:分组、批量、单个标签三个层级都有撤销
- **重复保存统计与版本谱系**:每个标签记录保存时刻;同一网址存过多次时显示 ×N 徽章(点击查看每次保存
  并跳转定位);标题有多个版本时徽章升级为**谱系条**(按版着色刻点,悬停列出每版标题与首末观测),
  菜单与洞察中每条观测带 v1/v2 版本标注;侧边栏「重复统计」面板按次数
  汇总所有重复网址;保存后提示"其中 M 个网址此前已保存过"
- **时间轴视图**:工作日志(带 +N/−M 差分)与收藏分组按天浏览;支持搜索过滤;一键恢复、定位或"把这一天找回来"
- **键盘列表导航**:`↑`/`↓` 在卡片间移动,`Enter` 恢复/开工,`Del` 删除(可撤销),`Esc` 取消
- **首次引导**:空库时显示三步引导卡(保存 → 整理 → 收工),可一键关闭
- **存储仪表**:设置页显示本地存储用量与资产计数
- 排序(手动 / 时间 / 标题 / 标签数)与外观主题(亮 / 暗 / 跟随系统)自动记忆

**备份与恢复(三层)**
- **每日全量备份**:每 6 小时把分组 + 工作区完整存档,保留最近 7 份;设置中可一键覆盖恢复(恢复前自动再留底,可撤销)
- **云端备份(WebDAV)**:支持坚果云 / Nextcloud / 群晖等任意 WebDAV 服务;填入地址与账号即可测试连接、立即备份、从云端恢复;可开"每日自动上传";按需授予站点权限(optional host permission),密码仅存本机,云端副本不含密码
- **崩溃恢复快照**:每 30 分钟快照打开中的标签(保留 3 份),可一键"恢复为分组"

**工作记忆(Record · 航海日志,不可变)**
- 每次**收工**自动生成一条工作记录:当时的全部标签 + 与上一记录的**时间差分**(+N/−M)
- **当时现场**:点开任意记录查看差分清单与全部标签;每枚标签带**来源链**徽章(在哪些分组/工作区/记录出现过,出现几次)
- **回到那一刻**三种方式:**续航恢复**(只打开现在没有的,不打断现场)/ 完整恢复(新窗口重建)/ 转为分组(收入收藏)
- **智能去重**:保存前检查——"当前窗口 17 个标签中 12 个已收藏过,只存新增的 5 个?"
- **数字速泊**:置顶分组自动占用 1–9 号泊位——popup 数字键或点击秒级恢复,地址栏 `harbor 2` 同效,分组卡片显示泊位角标
- **数据控制中心**:设置页三行状态(本机 / 你的 WebDAV / 第三方服务器从未),一键**验证最新备份**(可解析 ✓ 结构 ✓ 指纹 ✓ 规模)
- URL 归一化身份(#fragment、utm_*/fbclid/gclid 等追踪参数剥离;业务 query 不合并)是以上全部的底座

**工作区(整存整取的"工位",与分组互补)**
- **收工** `Alt+Shift+W`:把当前窗口整体存为命名工作区并关闭标签(popup 中可内联命名);
  可勾选**包含全部窗口**(多显示器每窗一条,`windows[]` 结构)
- **开工**:一键在新窗口恢复(多窗口工作区**逐窗口还原**),或扁平合并进当前窗口 / 替换当前窗口;
  固定标签原样保留
- 同名收工**先询问**(对话框实时显示将被覆盖的内容):「更新它」会记住、此后零提示(每天重复无摩擦),或「新建一个」(允许重名,身份独立);支持重命名、删除(可撤销)、导出为分组备份;
  多窗口卡片按"窗口 1/2…"分组展示,删除标签双结构同步
- 管理页顶部「分组 / 工作区」视图切换,`Ctrl+K` 可直达开工

**入口**
- **工具栏弹窗(点击图标)**:沿用原版「菜单条目 + 数量、点击即执行」的交互——
  「保存当前窗口标签(N)」「查看已保存分组(M 组 K 个)」,并增强:保存全部窗口(带窗口数)、
  在侧边栏常驻打开、设置与备份、记忆式保存选项(排除固定/当前页)、快捷键提示;
  保存成功后按设置智能收起(开了管理页就立即收起,没开则提示后收起)
- **Side Panel 侧边栏常驻面板**:分组列表、搜索、展开标签、快捷恢复(popup 中可一键打开)
- omnibox:地址栏输入 `bgt` + 关键词,直接搜索并打开已存标签
- 键盘:`Ctrl+K` 面板、`N` 新建分组、`?` 快捷键帮助、`Esc` 关闭

## 安装(开发者模式)

1. 打开 `chrome://extensions/`,开启右上角**开发者模式**
2. 点击**加载已解压的扩展程序**,选择本目录(`better-group-tabs`)
3. 建议在 `chrome://extensions/shortcuts` 确认 `Alt+S` 快捷键

### 从 v1.1.0 或 v3.11.x 升级

- v1.1.0:首次打开管理页时自动把旧版 `tabGroups` / `options` 迁移为 v2 结构
  (原数据备份在 `tabGroups_v1_backup`,并继承"恢复后删除分组"设置)。
- v3.11.3 及更早:单键 `bgtData` 首次加载时自动迁移为 v3 分键布局
  (`bgtMeta` / `bgtGroups` / `bgtWorkspaces` / `bgtRecords`,原数据留底 `bgtData_v2_backup`,可回滚;
  决策记录见 `docs/ADR-001-write-model.md`)。

## 已知限制

- 原生标签组导入/恢复、右键菜单、omnibox(`harbor` 关键词)、侧边栏需在真实 Chrome 116+ 中使用
  (116 是 `chrome.sidePanel.open()` 的下限,已对照 Chrome 官方 sidePanel 参考核实)
- **本地知识库出口**(设置 →「本地文件夹」):导出全部分组为 Markdown;**今日证据段**按日期写入 `tab-harbor-YYYY-MM-DD.md` —— 只更新两行托管标记之间的内容(区段外逐字节保留,覆盖前留底 .bak.md)
- **会话观测(可选,默认关)**:开启后记录**地址与标题**(不记内容、按键、滚动),统计会话内打开
  次数与停留,收工折叠进记录;缓冲只在本次浏览器会话,一键可清;**阅读路径**:会话内
  的访问顺序一键导出为 Markdown(研究路径,PKM 拿不到的那一层)
- 云端备份为 WebDAV 协议:不支持 OAuth 网盘(如纯网页版 Dropbox);WebDAV 密码以明文存于本机 `chrome.storage.local`,云端副本已剥离密码
- `dev-server.js`、`test/`、`tools/` 为开发文件。**不要手工压缩打包** —— 用 `node tools/pack.js`:
  它按显式白名单只装入运行时文件,并校验页面引用的资源是否齐全
  (v3.11.2 的商店包因手工压缩混入了 `test/` 与一份内部备忘录)
- 预览模式(mock)下,依赖后台的动作(保存全部窗口、原生分组等)会给出模拟提示

## 国际化

双语(中/英)内置,按浏览器语言自动切换:
- `manifest.json` 使用 `_locales/`(zh_CN 默认 + en),扩展名称、描述与快捷键说明随语言变化
- 页面与 JS 文案走轻量字典 `shared/i18n.js`(中文原文即键,en 查表,约 300 条;漏译优雅降级为中文)
- 静态 HTML 由 `BGTI18N.apply()` 在加载时替换文本节点,零模板改动;日期格式跟随浏览器语言

## 性能与资源

- **零依赖、无构建**:商店包约 120KB;Service Worker 事件驱动,空闲自动卸载
- **URL 归一化缓存**(1 万条,**真 LRU** —— 命中刷新近度,热条目不再被批量保存挤掉)+
  **身份索引内容指纹记忆化**(数据未变时 ~15ms,不进入重建路径):大库重复渲染零压力。
  边界由 `test/perf.js` 的确定性断言看守
- **低价值状态变更防抖落盘**(折叠/显示归档/排序/主题等 300ms 合并,页面隐藏或关闭时立即刷出),
  数据型操作(保存/收工/删除/合并/重命名)即时落盘。
  v3.11.4 起按集合分键(ADR-001):改名/置顶这类高频写只写被触集合,不再整库重写
- **DOM 批量挂载**(DocumentFragment)+ 搜索走轻量路径(不重建 DOM)
- **右键菜单指纹守卫**:内容未变化不重建;撤销栈收敛 10 步控制内存
- 压力基线(120 组 1440 标签 + 150 条记录):全量渲染 ~103ms、搜索 ~9ms、时间轴差分 ~24ms、堆 ~25MB
- 数据层基准:`node tools/test-all.js`(相对基线 ×3 容差,绝对毫秒阈值会假失败)

## 数据与隐私

所有数据默认只存本地 `chrome.storage.local`。扩展本身不向任何第三方服务器发送数据:
唯一的网络出口是你**自己配置**的 WebDAV 云端备份(未配置时不发起任何网络请求)。
云端副本上传前会剥离 WebDAV 密码;该密码本身以明文存于本机 `chrome.storage.local`,
请勿在共享浏览器配置中使用。隐私政策即架构本身。

写操作经上下文内串行队列,并以变更令牌过滤自回声;导出文件带 `version` 字段可安全再导入。

## 与 v1 的主要差异

| 方面 | v1.1.0 | v2.1.0 |
